# Angelcam API

> Angelcam is a cloud video-surveillance platform that connects any IP camera (via ONVIF and the open-source Arrow connector) to the cloud for live viewing, cloud recording, clip sharing, two-way audio, and Remote Technical Surveillance (RTS) event notifications. The RESTful API is HTTPS-only JSON, organised around Spaces, and secured with OAuth2 or a Personal Access Token.

- Base URL: https://api.angelcam.com/v1 (trailing slash required on all URLs)
- Auth: OAuth2 (authorization code) or Personal Access Token — Authorization: PersonalAccessToken {token}
- Pagination: limit/offset with count/next/previous/results (default limit 100)
- Rate limits: 30 requests/minute, 1000 requests/hour (HTTP 429)
